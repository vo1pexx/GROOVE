## Як запустити

Завантажте репозиторій і відкрийте `index.html` у браузері. Або у Visual Studio Code встановіть розширення **Live Server** і виберіть *Open with Live Server*. Для шрифтів потрібен доступ до інтернету (Google Fonts); без нього використовуються системні шрифти.

## Структура проєкту

```
groove/
├── index.html … design-system.html   # сторінки
├── css/
│   ├── tokens.css       # змінні: кольори, шрифти, відступи, радіуси
│   ├── base.css         # скидання стилів, типографіка, доступність
│   ├── layout.css       # контейнер, header, footer, сітки
│   ├── components.css   # кнопки, картки, форми, бейджі, трек-лист…
│   ├── pages.css        # стилі окремих сторінок
│   └── responsive.css   # медіазапити
└── images/              # SVG-обкладинки, заглушки виконавців, favicon
```

## Дизайн-система

Токени зібрано в `css/tokens.css` (CSS custom properties).

| Токен | Значення |
|---|---|
| `--color-bg` | #141414 |
| `--color-surface` | #1E1E1E |
| `--color-text` | #F4EDE0 |
| `--color-beige` | #D8C7A8 |
| `--color-accent` | #C4673F |
| `--color-text-muted` | #9A958C |

Текст на акцентному фоні — темний (`#141414`, контраст 4.70:1), бо світлий має лише 3.37:1. Шрифти: **Newsreader** (заголовки) та **Manrope** (основний текст).

## Адаптивність

| Режим | Ширина | Особливості |
|---|---|---|
| Desktop | > 1100 px | повна навігація, бічна панель фільтрів, 3–4 товари в ряд |
| Tablet | 601–1100 px | 2–3 товари в ряд, навігація в hamburger-меню (≤ 900 px), фільтри в окремій панелі |
| Mobile | ≤ 600 px | 2 товари в ряд, компактний header, підсумок кошика під списком |

Hamburger-меню, панель фільтрів і модальне вікно реалізовано чисто на CSS (`:checked`, `:target`).

## Семантика та доступність

- семантичні елементи `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `dl`, `table`;
- посилання «Перейти до основного змісту», видимий `:focus-visible`, `aria-label` для іконок;
- `alt` для всіх зображень, `label` для всіх полів, `aria-invalid` та `role="alert"` для помилок;
- `prefers-reduced-motion` вимикає анімації.
